┌─[Что это]──────────────────────────────────────────────────────────────────┘
│   theX  -  это декодер спектрумовской графики для плагина PictureView Павла
│ Скакова.  theX   поддерживает   интерфейс   PVD  плагинов-декодеров   v1.0.
│ Соответсвенно для  его работы требуется PictureView не ниже версии 1.4.1 от
│ 20.03.2007, который на момент написания документации был доступен по адресу
│ http://rain.ifmo.ru/~skakov/pictureview_141.rar 
│   Главная  задача  theX'а  просматривать  32  (!)  популярных  (и не очень)
│ графических формата не выходя из ФАР'а и не запуская внешних программ.
·

├─[Замечу что...]────────────────────────────────────────────────────────────
│  файлы в форматах ColorScreen, lc4 и lc5.2 содержат две страницы. Первая -
│   цветное изображение, вторая - черно-белое (если не использовался аттрибут
│   flash).
│  ChunkScreens тоже двухстраничные: "мешанина пикселов" + grayscale
│  Поскольку формат хранения битпланов в RGB триколорах определить нельзя,
│   первая страница - screen, вторая - спрайт
│  при проигрывании спрайтовых анимаций задержка не учитывается
│  и вообще, смотрите на количество страниц, которое показывает PictureView
│   и нажимайте Ctrl+PgUp[Dn] если что....
·
·
├─[Совместимость с xLook'ом]──────────────────────────────────────────────────
│   Well,  xLook ведет себя не по-пионерски и отрезает у HoBeta файлов header
│ при  просмотре.  Что отрицательно влияет на "интелект" theX'а и он не может
│ определить  формат файла в большинстве случаев. В связи с этим рекомендации
│ "лучших собаководов":
│
│  настройте PictureView чтобы он реагировал на Enter
│  или смотрите картинки по Ctrl+Shift+F3
·
·
├─[The Underscore]────────────────────────────────────────────────────────────
│   Если вы используйте  этот плагин, то убедитесь что его версия не ниже 1.0
│ pre-beta  1  build  153. Иначе возможны "интересные" визуальные эффекты при
│ листании  кнопочками PgUp/PgDn в режиме просмотра (в панели QuickView таких
│ проблем нет).
·
·
├─[Чуть не забыл]─────────────────────────────────────────────────────────────
│   Теоретически theX поддерживает  и  gflLib  read/write  API, поэтому после
│ переименования  его  можно  использовать  так  же как и xGfx.dll. Но в этом
│ случае появляются следующие ограничения:
│
│  смотреть можно только файлы с расширениями !s, $s, !f, $8, scr
│  о нескольких страницах можно забыть
│  анимация (в спрайтах) и flash не работают
│
│   Напомню  что в таком  случае  theX  может  работать  с  XnView и плагином
│ PicViewAdv  для  FAR Manager (возможно есть и другие программы использующие
│ gflLib,  а  значит  и  они  будут знать про Speccy). К сожалению соглашения
│ по  использованию User Plugins в разных версиях библиотеки меняются поэтому
│ можно попробовать два подхода:
│
│  имя плагина удовлетворяет маске x*.dll и он лежит в каталоге pluginsEx
│  имя - x*.usr и лежит в - plugins (XnView 1.8 и выше)
