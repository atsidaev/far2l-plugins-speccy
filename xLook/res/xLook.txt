┌─[О программе]───────────────────────────────────────────────────────────────
│    xLook  является  плагином  к  FAR'у для просмотра файлов системы TR-DOS в
│ формате HoBeta а также для их конвертирования.
│    Поддерживаются форматы:
│    1. Упаковщики:  HRUM 3.5i, HRUST 1.x, HRUST 2.1, HRUST 2.2+, MSPACK 1.96,
│    Code  Cruncher  3.11,  Data  Squeezer 4.12, Powerfull Code Decreaser 6.x,
│    LZS, Trush Compressor;
│    2. Ассемблеры: MASM, TASM, XAS, ZXASM, ALASM, STORM;
│    3. BASIC файлы;
│    4. откомпилированные модули некоторых музыкальных редакторов.
│    Поддержка   форматов   ведется  через  плагины  второго  уровня,  поэтому
│ поддержка  нового типа файла может быть легко добавлена без изменения самого
│ плагина.
·
·
├─[Установка]─────────────────────────────────────────────────────────────────
│ 1. Создайте каталог xLook в каталоге FAR/Plugins
│ 2. Скопируйте все файлы из архива в этот каталог
│ 3. Если у вас установлен AY_Emul то укажите путь к нему в файле ASSOCIAT.ION
│ 4. Перезагрузите FAR
│ 5. Настройте ассоциации файлов, например так:
│    Типы файлов:
│    *.$*,*.!*
│    Команда просмотра, выполняемая по F3:
│    xv:!.!
│    Команда редактирования, выполняемая по F4:
│    xe:!.!
